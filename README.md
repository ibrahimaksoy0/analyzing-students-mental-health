# Analyzing Students' Mental Health

This is a small SQL project I worked on using the Students' Mental Health dataset from DataCamp.

The main goal of the project is to look at the mental health scores of international students and see how they relate to their length of stay.

## What I used

* SQL
* SELECT
* WHERE
* GROUP BY
* COUNT
* AVG
* ROUND
* ORDER BY

## About the analysis

I mainly worked with the students' length of stay and their PHQ-9, SCS, and ASISS scores.

The SQL queries used for the analysis can be found in `analysis.sql`.
